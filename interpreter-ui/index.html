Interact with Postgres tables live — no code generation

This is the DDL interpreter mode. Enter Postgres credentials, and we'll interpret the schema at runtime: one live page per table with pagination, Create / Update / Delete, and in-UI error banners — all without writing any generated files to disk.

Quick start

  • Click Connect to Postgres at the top-right (or use the link in the sidebar) to enter credentials.
  • The credential dialog has two modes — pick Interact live (no code generation).
  • After connecting, pick any table from the left sidebar to browse rows, modify, create, or delete.
  • You can re-enter credentials at any time by clicking the connection pill or Connect to Postgres in the header — even while already connected.
